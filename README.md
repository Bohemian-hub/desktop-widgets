# 桌面组件 · Electron 版（MVP）

把原来基于 Plash 的桌面组件系统，改造成 **Electron 原生应用**。
**每个组件 = 一个独立的透明无边框窗口**，窗口尺寸刚好等于组件尺寸。

## 和 Plash 的本质区别

| | Plash | 本方案 (Electron) |
|---|---|---|
| 窗口 | 单个全屏 WebView | 每个组件一个独立窗口 |
| 鼠标 | 全局开关：穿透 or 捕获，二选一 | 组件窗口内网页可点击；窗口之外天然穿透给桌面 |
| 文件夹 | 穿透时才能点 | 随时都能点（组件只占屏幕一小块） |
| 组件开发 | 在 index.html 里加 script 标签 | 文件丢进 widgets/ 即自动加载 |

## 目录结构

```
桌面组件-electron/
├── main.js              # 主进程：扫描 widgets/，为每个组件创建独立透明窗口
├── preload.js           # 桥接：渲染进程 ↔ 主进程
├── renderer/
│   ├── widget.html      # 组件窗口模板（含通用组件样式 + 拖拽把手）
│   ├── widget-render.js # 组件渲染器：加载组件 js、注入 CSS/HTML、调用 init
│   ├── dock.html        # 桌面右下角竖排 Dock：显示=蓝色图标，隐藏=灰色
│   └── control.html     # 控制台：显示/隐藏组件、重新加载、退出
├── widgets/             # 组件目录（一个组件 = 一个文件夹）
│   ├── course/          # 课程表组件
│   │   ├── widget.js    #   组件定义（逻辑）
│   │   ├── data.json    #   组件数据（课表数据，独立存放）
│   │   └── icon.svg     #   组件图标（独立文件）
│   ├── todo/            # 待办组件（数据实时读写 data.json）
│   │   ├── widget.js
│   │   ├── data.json
│   │   └── icon.svg
│   └── _template/       # 新组件模板（整文件夹复制改名即可）
└── scripts/gen-icon.js  # 生成托盘图标
```

## 运行

```bash
cd ~/Desktop/桌面组件-electron
npm install        # 首次安装依赖
npm start          # 启动
```

- 退出：菜单栏托盘图标（蓝色圆角方块）→ 退出
- 控制台：托盘 → 打开控制台（或点击 Dock 图标）

## 开发新组件

1. 复制 `widgets/_template/` 整个文件夹，改名为你的组件（如 `clock`）
2. 修改 `widget.js`：`id / name / width / height / css / html / init`
3. 需要的数据填进 `data.json`，图标换成 `icon.svg`
4. 控制台点「重新加载组件」（或重启 App）即可

**不需要改任何主进程代码**，启动时自动扫描 `widgets/*/widget.js`（`_` 开头文件夹会被跳过）。

### 组件数据说明

每个组件文件夹可带一个 `data.json`，存放组件需要的数据：

```js
// 读取（init 的第二个参数 data 已自动传入，也可随时再读）
const data = await window.desktopAPI.readData('todo');

// 写入（会保存到 widgets/todo/data.json）
window.desktopAPI.writeData('todo', { todos: [...] });
```

- 课程表：课程数据全部在 `course/data.json`，改数据不用碰代码
- 待办：待办清单实时读写 `todo/data.json`，取代了浏览器 localStorage，数据跟着组件文件夹走

## 已实现

- [x] 多组件独立透明窗口（课程表 600×300、爱情 600×300、待办 300×630、**桌面宠物 300×300**）
- [x] **积木布局**：按宽度分组自动排列，同宽组件上下堆叠、不同宽左右拼接，组件间距统一 **30px**、互不重叠（托盘 →「重新排列组件」一键摆齐；组件高度对齐公式：待办 630 = 课表 300 + 30 + 爱情 300）
- [x] 组件区域网页可点击（已实测：点「下一天」课程表日期正常切换）
- [x] 窗口以外区域点击直达桌面（文件夹图标不受遮挡）
- [x] 拖拽组件顶部标题栏移动窗口，位置自动持久化（`~/Library/Application Support/桌面组件/widget-state.json`）
- [x] **桌面右下角竖排 Dock**（固定在右下角，屏幕分辨率变化自动重新贴边）：
  - 每个组件一个图标，**显示中 = 蓝色，隐藏 = 灰色**
  - 点击图标切换组件显示/隐藏，Dock 与控制台状态实时双向同步
  - 新增组件后 Dock 自动多一个图标，无需改代码
- [x] 控制台：显示/隐藏组件、重新加载、退出
- [x] **全局透明度滑块**（控制台）：统一调节所有组件外层卡片背景透明度（15%~100%），实时生效、自动持久化（重启保持）
- [x] **壁纸模式 + 交互锁定**（控制台，两个独立开关，组合出四种桌面形态）：
  - **壁纸模式**：组件层级降到桌面图标/文件夹之下，图标浮在组件上层、不被遮挡
  - **交互锁定**：组件不响应鼠标/键盘，点击穿透到桌面
  - 壁纸模式开 + 交互锁定关 = **置底 + 可交互**（组件在图标之下，仍可点击/输入/拖动，通过透明交互代理窗口转发事件）
  - 壁纸模式开 + 交互锁定开 = 纯背景展示（可看不可点）
  - **交互代理层放在 App 窗口之下（层级 -1000）**：桌面上组件可点；任何软件窗口打开时自然盖住代理层，正常操作软件、互不干扰（已实测：TextEdit 覆盖组件区域后点击命中 TextEdit）
  - **点击后键盘焦点交给组件窗口**：中文输入法、Cmd+V 粘贴由系统直达组件（已实测：粘贴中文进 todo 成功）；标题栏拖动改为"位移超过阈值才判定"——标题栏里的按钮（课表翻页、图标隐藏）照常可点
- [x] **组件窗口左上角图标**：显示组件自己的图标（来自文件夹的 `icon.svg`），**点击图标直接隐藏该组件**（Dock 图标同步变灰）
- [x] **桌面宠物组件**（300×300）：照片头部 + Q 版卡通身体的五种姿态（爬行常态 / 压扁 / 跳跃 / 吃饭 / 睡觉，透明 PNG 素材在 `widgets/pet/assets/`）：
  - 点击宠物：轮流触发 吃饭→睡觉→跳跃→压扁 互动，随机简短对白
  - 空闲时（12~32 秒随机）：说出「我爱你」等有趣中文对白，白色不透明气泡、不遮挡角色
  - 右键菜单：吃饭 / 睡觉 / 跳跃 / 压扁 / 说我爱你
  - 对白文案放在 `widgets/pet/data.json`，可随意修改
  - **素材说明**：仓库不包含宠物姿态素材（`widgets/pet/assets/*.png`，原为真人照片生成的透明 PNG）。使用时自行放入 5 张透明背景 PNG：`crawl.png`（爬行常态）、`squashed.png`（压扁）、`jump.png`（跳跃）、`eat.png`（吃饭）、`sleep.png`（睡觉），放好后重启即生效。

## 已知限制（MVP）

1. **毛玻璃效果**：Electron 透明窗口的 `backdrop-filter` 无法模糊桌面内容（Electron 已知限制），
   目前用卡片半透明（0.5~0.78）透出壁纸；后续可改用 macOS `vibrancy` 实现真毛玻璃。
2. **圆角外区域**：窗口是矩形，卡片圆角外的透明角落像素仍会拦截桌面点击；
   目前组件边距小影响不大，后续可用原生透明点击区域优化。
3. **窗口层级**：默认窗口模式下组件是普通层级（桌面图标之上、应用窗口之下）；
   打开其他 App 时组件会被盖住，回到桌面可见——这是符合直觉的行为。
4. **壁纸模式 + 交互的取舍**：壁纸模式下组件区域内的点击会命中组件（可交互组合），
   该区域上的桌面图标**可见但点不到**（点击归属组件）；组件摆放避开图标区域即可。
   壁纸模式依赖 `setAlwaysOnTop` 负偏移，个别 macOS 版本可能表现不一致，如异常可重启应用恢复。
   另：代理层（透明）在组件区域下方，**鼠标经过时无视觉、不拦截任何软件窗口**；
5. **多显示器 / 多桌面（Space）**：默认只在启动时所在显示器/桌面显示，未做跨屏同步。
6. 组件数量建议控制在 10 个以内（每个组件一个 Chromium 渲染进程，会占内存）。

## 常见问题

- **启动后组件没出现**：看终端日志是否打印 `[widgets] 已加载 xxx.js`；
  组件文件若开头是 `_`（如 `_template.js`）会被跳过。
- **想重置组件位置**：删除 `~/Library/Application Support/桌面组件/widget-state.json` 后重启。
- **沿用原 Plash 项目的组件**：直接把 `js` 文件复制进 `widgets/` 即可，格式完全兼容。
